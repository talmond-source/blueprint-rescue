# Blueprint Rescue

A 3D Cell City DNA game for PBS 1.1.5 (Mr. Almond).

- `index.html`: **Chromebook edition** (lighter graphics). This is the student link.
- `board.html`: full-graphics edition for the classroom board.
- `mobile/`: **phone edition** (touch controls, portrait or landscape). Open it in Safari or Chrome and use Add to Home Screen; it works offline after the first visit.

Both versions play the same game, and their completion codes match.
